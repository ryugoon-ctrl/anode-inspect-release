준비물

  • 검수 USB: 8GB 이상. 윈도우·맥 모두에서 쓰려면 exFAT 형식. 개인 파일·인증서가 없는 검수 전용 USB 권장
  • 검수할 노트북: 사전 작업자가 OS를 다시 설치하고, 임시 계정으로 바탕화면까지 들어간 상태. 와이파이 등 네트워크 연결
  • 포트 테스트용: USB 메모리 1개, 외부 모니터와 케이블(HDMI 등), SD 카드, 충전기
  • 이어폰 (이어폰 단자가 있는 기종)
중요회사 보안 프로그램이 설치된 사내 PC는 USB 쓰기·프로그램 실행이 막혀 결과 저장이 실패함. 알파 테스트는 회수 기기 등 보안 프로그램이 없는 기기로 진행

검수 USB 만들기

  1. 위 버튼으로 anode-inspect-alpha.zip 내려받기
  2. 압축 풀기. anode-inspect 폴더 1개가 나옴
  3. anode-inspect 폴더를 USB 최상위에 그대로 복사 (폴더 이름·안의 구성 변경 금지)
USB/
└── anode-inspect/
    ├── ANODE-USB.json     검수 USB 표식 (지우면 결과 저장 불가)
    ├── inspector-mac/     맥 앱
    ├── inspector-win/     윈도우 앱과 smartctl.exe
    ├── results/           검수 결과 (기기별로 자동 생성)
    ├── exports/           엑셀 결과 (첫 저장 때 자동 생성)
    ├── licenses/          동봉 프로그램 라이선스
    └── manual.html        이 안내문 사본 (로고 파일 2개 포함)
참고앱은 실행된 위치에서 ANODE-USB.json을 찾아 그 폴더에 결과를 저장함. 앱만 따로 다른 곳에 복사하면 저장 불가

맥에서 실행

처음 한 번: 인터넷에서 받은 파일 표시 해제

인터넷에서 받은 앱은 맥이 임시 위치로 옮겨 실행해서 검수 USB를 찾지 못함. USB를 꽂은 뒤 터미널에서 아래 한 줄 실행

  1. 터미널 열기: ⌘+스페이스로 Spotlight를 열고 "터미널" 입력 후 Enter
  2. 아래 명령에서 USB이름을 Finder에 보이는 USB 이름으로 바꿔 붙여넣고 Enter
xattr -dr com.apple.quarantine "/Volumes/USB이름/anode-inspect"

실행

  1. USB의 anode-inspect/inspector-mac/anode-inspector 앱 더블클릭
  2. 실행이 막히면: 시스템 설정 → 개인정보 보호 및 보안 → 아래쪽 "그래도 열기" → 다시 실행
  3. 카메라·마이크 접근 요청은 허용 (카메라·마이크 테스트에 필요. 영상·녹음은 저장하지 않음)
주의맥은 활성화 잠금(Apple 계정)이 풀린 초기화 기기만 검수 대상. 자동 수집 결과에 "활성화 잠금 켜짐"이 나오면 매입 중단 사유

윈도우에서 실행

  1. 스마트 앱 컨트롤 끄기 (새로 설치한 윈도우 11은 서명 없는 앱을 막음): 설정 → 개인 정보 및 보안 → Windows 보안 → 앱 및 브라우저 컨트롤 → 스마트 앱 컨트롤 → 끄기. 검수 후 같은 위치에서 다시 켤 수 있음
  2. USB의 anode-inspect\inspector-win\anode-inspector.exe를 마우스 오른쪽 버튼 → 관리자 권한으로 실행 (TPM·저장장치 정보에 필요)
  3. "Windows의 PC 보호" 파란 창이 뜨면: 추가 정보 → 실행

검수 순서

순서내용
1. 기기 확인왼쪽 위 "검수 대상"에서 모델명·시리얼 확인. "시리얼 (펌웨어)" 값이 비어 있거나 기기 하단 라벨과 다르면 "라벨 시리얼"에 라벨 값 입력. 상단 "검수자"에 이름 입력
2. 자동 수집앱을 켜면 배터리·저장장치·와이파이·블루투스·OS·잠금 상태를 자동으로 읽어 "자동 수집 결과"에 표시 (몇 초). "확인 필요" 항목은 안내대로 조치 후 "다시 수집". 확인이 끝나면 "수동 검수 시작" (다시 보려면 왼쪽 "자동 수집 결과")
3. 반자동키보드·지문 인식·포트·마이크·카메라·전원. 각 항목 화면의 테스트 버튼("키 입력 테스트", "포트 테스트" 등)으로 테스트하면 앱이 상태를 제안하고, 검수자가 "적용"을 눌러야 선택됨
4. 수동외관·힌지·디스플레이·스피커 등. 항목마다 "확인 방법"을 열어 기준을 보고 상태 선택. 디스플레이는 "단색 화면 테스트", 스피커는 시험 음 사용
5. 결과 저장하단 "결과 저장". 확인 안 한 항목이 있어도 저장 가능 (저장 후 안내에 개수 표시)

포트 테스트

  • 애플 실리콘 맥: 기기의 포트 목록이 자동으로 나옴. 포트마다 USB 메모리·모니터·SD 카드를 한 번씩 연결하면 "확인됨". USB-C는 충전기만으로는 확인되지 않음 (데이터 연결 필요)
  • 윈도우·인텔 맥: USB 포트 수를 입력하고 포트마다 USB 메모리를 꽂았다 빼기. 검수 USB가 꽂힌 포트는 자동으로 확인됨. 모니터·SD 카드는 연결하면 인식

키 입력 테스트

화면에 표시된 필수 키를 한 번씩 입력 (점선 테두리의 선택 키는 기종에 따라 없음). 기능열(F1~F12)은 fn을 누른 채 입력. 끝내려면 "테스트 닫기" 또는 Esc를 2초 길게 누름. 인식되지 않는 키가 있으면 화면 아래 "마지막 입력" 줄을 캡처해서 보고

결과 저장과 회수

  • 결과 파일: anode-inspect/results/시리얼/ 아래 JSON 파일. 기기마다 폴더 생성
  • 엑셀: 하단 "USB에 엑셀도 저장"이 켜져 있으면 (기본 켜짐) anode-inspect/exports/검수결과_날짜.xlsx에 그날 검수한 기기 전체가 재고관리 양식 열 순서로 저장됨
  • 구글 시트: 관리자가 설정한 USB에서만 자동 전송. 하단에 "구글 시트: 전송 완료" 또는 "구글 시트: 대기 N건" 표시. 대기 건은 다음 저장·앱 실행·"다시 보내기" 때 전송. 설정 없는 USB는 "구글 시트: 설정 없음 (USB에만 저장)" 표시 (정상)
  • 테스트가 끝나면 USB의 results·exports 폴더를 담당자에게 전달
참고엑셀의 STATUS는 앱의 제안값이고 등급 칸은 비워 둠. 등급과 STATUS는 담당자가 확정

알파 테스트 확인 목록

기기마다 아래를 확인하고 다른 점을 보고. 비교할 값을 확인하기 어려우면 앱 값만 기록

구분확인할 것
기기 정보모델명·시리얼이 기기 라벨과 같은지
배터리최대 용량·사이클이 실제 값과 같은지. 맥: 시스템 설정 → 일반 → 정보 → 시스템 리포트 → 전원. 윈도우: 명령 프롬프트에서 powercfg /batteryreport 실행 후 안내된 위치의 battery-report.html 열기 (DESIGN·FULL CHARGE CAPACITY, CYCLE COUNT)
저장장치"남은 수명"이 표시되는지. CrystalDiskInfo가 있으면 "건강 상태"와 비교
반자동포트 테스트에서 포트가 모두 인식되는지, 전원 항목이 충전기 연결을 2초 안에 반영하는지
테스트 화면단색 화면·키 입력·스피커·이어폰·마이크·카메라 테스트가 동작하는지
저장결과 저장 후 USB에 결과 파일과 엑셀이 생기는지, 엑셀 내용이 맞는지
사용성헷갈리는 문구·버튼, 현장에서 불편한 순서

문제 보고

관리자가 공유한 구글 시트의 피드백 탭에 한 줄씩 작성. 다른 탭(재고행·원본)은 수정하지 않음

  • 기기 모델명과 OS 버전 (앱 왼쪽 위 "검수 대상"에 표시)
  • 문제가 생긴 화면 캡처. 안내 문구 아래 "상세"가 있으면 펼쳐서 함께 캡처
  • 화면 오류가 나면 앱이 오류 내용을 표시함. 그 화면 그대로 캡처
  • 실제 값과 앱 값이 다르면 둘 다 기록 (예: 배터리 리포트 82%, 앱 86%)
  • 캡처는 구글 드라이브에 올리고 링크를 "캡처 링크" 칸에 붙여넣기 (셀에 이미지 직접 넣기도 가능)

알려진 제한

  • 코드 서명 전이라 맥 실행 차단 안내, 윈도우 "Windows의 PC 보호"·스마트 앱 컨트롤 안내가 뜸
  • 윈도우 포트 테스트는 포트 수를 직접 입력하는 방식 (윈도우가 물리 포트 목록을 정확히 제공하지 않음)
  • 윈도우 기기 정보 수집은 확인한 기종이 적음 (앱 상단 "시험판" 표시)
  • 맥은 모니터가 HDMI·USB-C 중 어디로 연결됐는지 구분하지 못함
  • HDD는 저장장치 남은 수명을 표시하지 않음

구글 시트 전송 설정 (관리자)

배포 묶음에는 전송 설정이 없음 (공개 배포 파일에 비밀값을 넣지 않기 위함). 시트 전송까지 시험할 USB는 관리자가 anode-inspect/ANODE-USB.json에 사내로 따로 전달한 sheets 항목을 추가

{
  "kind": "anode-inspect-usb",
  "sheets": { "url": "관리자 전달 주소", "token": "관리자 전달 값" }
}
