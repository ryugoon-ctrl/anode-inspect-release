# a-node 검수 앱 알파 배포

회수 노트북(윈도우·맥) 검수 앱의 사내 알파 테스트용 배포 저장소. 실행 파일과 안내문만 있음 (소스 코드는 비공개 저장소).

- 안내문: https://ryugoon-ctrl.github.io/anode-inspect-release/
- 내려받기: [최신 검수 USB 묶음 (zip)](https://github.com/ryugoon-ctrl/anode-inspect-release/releases/latest/download/anode-inspect-alpha.zip)
- 버전별 변경 내용: [Releases](https://github.com/ryugoon-ctrl/anode-inspect-release/releases)

동봉 프로그램: smartctl (smartmontools 7.5, GPL-2.0). 라이선스 고지와 소스는 묶음의 `licenses` 폴더.
